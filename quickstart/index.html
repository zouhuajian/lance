Getting Started with Lance¶

Lance is an open lakehouse and columnar table format for multimodal AI. Every tool in the Lance ecosystem reads and writes the same on-disk format, so you can start at the layer that matches your application and interoperate across layers without copying or converting data.

The Lance Stack¶

| 1. Database                LanceDB (Embedded & Distributed)         |
+---------------------------------------------------------------------+
| 2. Language SDKs           Python (PyLance), Rust, Java             |

Choose Your Entry Point¶

1. Database — LanceDB¶

Choose LanceDB when you are building an AI application, RAG pipeline, or search service and want table management, vector search, BM25 full-text search, and hybrid reranking out of the box.

  • LanceDB Quickstart — Create a table, run vector and keyword search, update rows, and time travel in 5 minutes.
  • LanceDB Documentation ↗ — Embeddings, hybrid reranking, TypeScript/Python/Rust database clients, and Cloud/Enterprise deployments.

2. Language SDKs — Python, Rust, and Java¶

Choose a Language SDK when you want direct, low-level control over Lance datasets, fragments, custom Arrow schemas, multimodal Blob v2 columns, or distributed write transactions.

Language Package Quickstart API Reference

3. Query & Compute Engines¶

Choose a Query or Compute Engine when you want to run distributed SQL, lakehouse ETL, analytics, or large-scale ML training over Lance tables alongside existing data pipelines.

Engine Typical Workload Get Started
Apache Spark Distributed SQL, DDL/DML, and batch ETL with Spark SQL and PySpark Spark Quickstart · Spark Connector Docs
DuckDB / Trino / DataFusion Interactive SQL analytics and federated queries over Lance datasets DataFusion · All SQL Integrations
Ray / PyTorch / Flink Distributed data processing, streaming ingestion, and ML training loaders PyTorch · All ML & Stream Integrations

One Format Across Every Layer¶

Because all layers share the Lance format specification, you can mix tools freely in a single pipeline — for example, ingest and backfill features at scale with Apache Spark, build vector and full-text indexes with the Python or Rust SDK, and serve low-latency hybrid queries from LanceDB.
